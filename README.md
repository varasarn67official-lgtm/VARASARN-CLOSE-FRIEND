# Varasarn Close Friends

พื้นที่สำหรับนักศึกษาคณะวารสารศาสตร์และสื่อสารมวลชนในการค้นหารายวิชา อ่านและแบ่งปันรีวิว และจัดตารางเรียน ทั้งหลักสูตรภาคปกติ (JC) และหลักสูตรนานาชาติ (BJM)

## Features

- ค้นหารายวิชาด้วยรหัส ชื่อวิชา หรือหมวดหมู่
- อ่านคะแนนและความคิดเห็นจากเพื่อนนักศึกษา
- เขียนและจัดการรีวิวของตนเอง
- เลือกกลุ่มเรียนและจัดตารางเรียน
- ใช้งานได้ทั้งบนโทรศัพท์และคอมพิวเตอร์

## Interface

Built with Vue 3 and TypeScript, with a responsive interface using Bootstrap.
